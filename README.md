## 📌 Descripción

Este proyecto corresponde a la **PFO1** y consiste en el desarrollo de una **landing page de portafolio personal** utilizando **HTML5 y CSS3**.

La página presenta:

* 👤 Presentación personal
* 🧠 Habilidades
* 📩 Información de contacto
* 🎨 Sección personal
* 📱 Diseño responsive
* ✨ Animaciones y transiciones CSS

El diseño fue desarrollado teniendo en cuenta diferentes tamaños de pantalla, principalmente **Tablet y Mobile**.

## 🎨 Decisiones de diseño

El diseño, la estructura de la página, la organización del contenido y la implementación del código fueron realizados **manualmente**.

Busqué crear una estética **moderna, personal y visualmente atractiva**, utilizando:

* 🌈 Colores y degradados
* 🔤 Tipografías personalizadas
* 📐 Distribución de elementos
* ✨ Efectos visuales
* 🎞️ Animaciones y transiciones
* 📱 Adaptación responsive

Cada elemento fue elegido de acuerdo con el estilo visual que quería transmitir en mi portafolio.

## 🤖 Uso de Inteligencia Artificial

Durante el desarrollo utilicé herramientas de inteligencia artificial como **apoyo creativo y de consulta**.

### 🟣 Gemini — Versión gratuita

Utilicé Gemini para generar **dos imágenes ficticias representándome como un personaje 3D**.

Estas imágenes fueron utilizadas como recursos visuales dentro de la landing page.

### 🟢 ChatGPT — Versión gratuita

Utilicé ChatGPT como herramienta de apoyo para **explorar y obtener propuestas de colores** para el diseño visual.

> 💡 Las sugerencias obtenidas mediante IA fueron revisadas y utilizadas únicamente como referencia. Las decisiones finales de diseño e implementación fueron tomadas por mí.
