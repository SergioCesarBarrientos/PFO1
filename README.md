PFO1 - Landing de Portafolio - Sergio Cesar Barrientos 

Descripción 
Este proyecto corresponde a la PFO1 y consiste en el desarrollo de una landing page de portafolio personal utilizando HTML y CSS. 

La página incluye una presentación personal, habilidades, información de contacto y una sección personal a elegir, además de un diseño responsive adaptado a distintos tamaños de pantalla. (Tablet & Mobile) 

Tecnologías utilizadas:
HTML5 
CSS3 
Google Fonts 
Flexbox 
Diseño responsive (Tablet & Mobile) 
Animaciones y transiciones CSS 

Decisiones de diseño:
El diseño, la estructura de la página, la organización del contenido y la implementación del código fueron realizados manualmente por mí. 
Elegí una estética moderna y personal, utilizando colores, degradados, tipografías, distribución de elementos y efectos visuales acordes al estilo que quería transmitir en mi portafolio. 

Uso de Inteligencia Artificial: 

Gemini : Version Gratuita 
ChatGPT: Version Gratuita 

Durante el desarrollo del proyecto utilicé herramientas de inteligencia artificial como apoyo creativo, pero la mayor parte del trabajo fue realizada manualmente. 

Gemini: utilicé esta herramienta para generar dos imágenes ficticias de mí representado como un personaje 3D. Estas imágenes fueron utilizadas como recursos visuales dentro de la landing. 

ChatGPT: lo utilicé como apoyo para obtener colores para el diseño visual. 

El código HTML y CSS, la estructura de la landing, la distribución de los elementos, el diseño responsive, las animaciones y el resto de las decisiones de implementación fueron realizados manualmente por mí. Las sugerencias obtenidas mediante IA fueron revisadas pero no aplicadas, la pagina fue hecha bajo mis propios criterios de diseño. 

Experiencia previa con IA:
Ya tenía experiencia previa utilizando herramientas de inteligencia artificial como apoyo para resolver dudas y explorar ideas. 

En este proyecto las utilicé principalmente como herramientas de consulta para buscar y explorar opciones de colores. Mantuve el control sobre las decisiones finales y la implementación del proyecto.
